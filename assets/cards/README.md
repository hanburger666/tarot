# 牌面素材

本目录包含 78 张 Pamela Colman Smith 绘制的 Rider–Waite–Smith 塔罗牌缩略图，来自 Wikimedia Commons 的 [Rider-Waite-Smith tarot deck (TaionWC)](https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)) 分类。

下载时通过 Wikimedia Commons API 逐张核对 `LicenseShortName` 为 `Public domain`。每张本地文件对应的来源页面记录在 [`sources.json`](sources.json) 中。请注意，同一套塔罗牌的现代重新上色版本可能有不同的版权状态；本目录仅收录上述分类中核验过的文件。

如需重新获取素材，可在项目根目录运行 `download_cards.ps1`。脚本会复核文件数量与授权状态。
